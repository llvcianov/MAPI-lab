# STM32 Embedded Exercises

Embedded C lab exercises for the **Ulteriori Conoscenze** (supplementary skills) module, Bachelor's Degree in Computer Engineering, University of Naples Federico II — bare-metal programming on the STM32F3 Discovery board (Cortex-M4), built with IAR Embedded Workbench.

> **Note**: university coursework, written for teaching purposes. Not meant to reflect modern production practices.

## [Progetti/](Progetti)

Progressive bare-metal exercises on GPIO, timers, and counters: LED blink, button-controlled LED, timer-based blinking, a counter driven by a shared peripheral library, and a final exam project. Each is a self-contained IAR Embedded Workbench project.

## [Manuali/](Manuali)

Official STMicroelectronics reference documentation for the STM32F3 Discovery board: datasheet, reference manual, HAL/LL driver description, user manual, accelerometer/magnetometer datasheet, and the Cortex-M4 programming manual.
